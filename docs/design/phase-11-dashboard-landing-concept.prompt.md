# Phase 11 dashboard and landing-page concept prompt

## Generation mode

Built-in image generation, using the supplied corporate sunset image as a style
and mood reference only.

## Prompt

Create a high-fidelity 16:9 product-design concept for Praxis that presents the
landing-page hero and authenticated dashboard as one coherent enterprise SaaS
system. Translate the reference image's blue-glass towers, warm amber sunset,
executive confidence, layered transparency, and cinematic depth into an
original interface without copying its people or composition.

The landing page uses the Praxis wordmark, the headline “Organizational memory
that argues with itself.”, concise supporting copy, and the calls to action
“Explore the decision graph” and “View live demo”. The dashboard is titled
“Praxis Control Room” and includes navigation for Overview, Decisions,
Assumptions, Estimates, Review Queue, and Evidence; an offline mock-provider
status; KPI cards; a decision-provenance graph from D-0042 through
`migration_weeks <= 6` and EST-0098 to a 1.8× optimism warning; a ranked review
queue; calibration factor, band, and confidence; and an evidence timeline.

Use deep navy, blue glass, restrained teal, warm amber, and ivory. Keep the UI
practical, accessible, implementation-ready, and free of lorem ipsum,
watermarks, unrelated logos, purple gradients, neon cyberpunk styling,
oversized rounded cards, fake 3D charts, and illegible microcopy.
